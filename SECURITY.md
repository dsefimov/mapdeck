# Security

Report suspected vulnerabilities privately. Do not open a public issue and do
not disclose vulnerability details publicly before the maintainers have
coordinated a fix with you.

## Reporting

- Email the maintainer: dmitry.efimov.spb@gmail.com.
- If the repository has GitHub private vulnerability reporting enabled, the
  "Report a vulnerability" form on github.com/dsefimov/mapdeck/security/advisories
  is an alternative route.

Include in the report:

- the affected package version (`mapdeck` version from your lockfile);
- steps to reproduce, or a proof of concept where safe to share;
- the observed impact (for example: data exposure, script injection into the
  host page, denial of service in a map view).

## Handling

The maintainer acknowledges reports and assesses them; confirmed issues are
fixed and released, and disclosure is coordinated with the reporter. Reporters
are credited in the release notes unless they prefer otherwise.

## Supported versions

Security fixes are prepared for the latest published release only.
